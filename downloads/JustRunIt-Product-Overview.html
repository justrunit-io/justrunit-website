Why customers choose Just Run It

  • Run where files live — federated Linux/Windows agents on hosts you control
  • Production job types — COMMAND (real shell), HTTP, GIT_RELEASE binaries, workflows, cron
  • Operate with confidence — execution history, logs, cancel/kill, orphan recovery, optional email
  • Multi-team governance — workspaces, RBAC, optional OIDC SSO, audit attribution
  • Known deploy paths — Docker Compose HA, Kubernetes/Helm, bare metal/VM

What ships

  • Web UI control plane and REST API
  • Jobs: COMMAND (shell), HTTP, NOOP, GIT_RELEASE (release asset download + execute)
  • Workflows with step conditions and restart from failed step
  • Cron schedules for jobs or workflows
  • Out-of-process agents (Linux, Windows, container hosts)
  • Personal, group, and platform workspaces for multi-team use
  • Local RBAC (VIEWER / OPERATOR / ADMIN) and optional OIDC SSO
  • Execution history, cancel/kill, orphan recovery, optional email notifications
  • Deploy via Docker Compose, Helm/Kubernetes, bare metal/VM, or sandbox JAR

Federated production use

  • Control plane — one shared HA deployment for multiple teams
  • Workspaces — personal and group isolation of catalogs; admin full visibility
  • Agents — installed on team systems; preferred agent pins jobs to the right host

Technology baseline

  • Java 21, Spring Boot, Thymeleaf UI
  • PostgreSQL for production deployments; H2 for local sandbox
  • Docker multi-stage builds; Helm chart for Kubernetes
